Methodology

Stage 0 (full universe, 503 tickers, no shortcuts): resolved each S&P 500 ticker to an IBKR contract via search_contracts, then pulled THREE_MONTHS/ONE_WEEK price history. 3-month return computed as (last close − first close) / first close. SPY's 3-month return was +4.19%; any ticker whose return fell more than 2.19 percentage points below that (i.e. below +2.19%) was discarded. 500 of 503 tickers were successfully classified this way (250 survivors / 250 discards); 3 tickers (BRK.B, BF.B, ECHO) could not be resolved to a tradeable NYSE/NASDAQ contract via bare-ticker search and were excluded — see Data quality panel.

Prioritization into Stage 1-4: given the scale of full daily-bar technical analysis across 250 survivors, this run carried forward the top 100 survivors by Stage-0 3-month return (strongest momentum first) into the deeper 4-criterion technical funnel below. This is a disclosed scope reduction from "all 250 survivors" to "top 100 by momentum" — see Data quality panel for the rationale and the excluded 150.

Stage 1-4 technical funnel (weekly-bar proxies, disclosed methodology adjustment): for resource reasons, Stage 1-4 uses ONE_YEAR/ONE_WEEK price bars (~52-53 points) rather than daily bars, with SMA windows adapted accordingly:

  • SMA50-equivalent → 10-week SMA (50 trading days ≈ 10 weeks)
  • SMA200-equivalent → 40-week SMA (200 trading days ≈ 40 weeks)
  • RSI14 computed with Wilder's method on the weekly close series (14-period)
  • 52-week high = max of the weekly high series over the full ~52-week window
  • Relative strength = ticker's 1-year total return vs SPY's 1-year return (+18.99%, contract 756733, 2025-09-05 → 2026-08-31)

Tier / funnel criteria (C1→C4, cumulative):

  • C1 — price above the 40-week SMA (long-term uptrend)
  • C2 — also above the 10-week SMA, with 10-week SMA > 40-week SMA (golden-cross posture)
  • C3 — also RSI14(weekly) in the 45-80 band (healthy momentum, not oversold/overbought)
  • C4 / HIGH — also within 15% of the 52-week high AND 1-year relative strength ≥ SPY + 5 percentage points

Tickers passing C1+C2 only are tagged WATCH; C1+C2+C3 are tagged MED; failing C1 or C2 is tagged NONE (did not clear the funnel). Only HIGH-tier names are written to momentum-latest.json, each with an entry price (latest weekly close) and a diversification note computed against the account's current 14 holdings (pulled once via get_account_positions).

Data quality & limitations

  • Weekly-bar proxy (Stage 1-4): SMA50/SMA200/RSI14/52wk-high are computed from ~52-53 weekly bars rather than ~252 daily bars (see Methodology). This is a coarser approximation and can shift SMA crossover timing and RSI values by a few points versus a daily-bar calculation; treat tier boundaries (e.g. HIGH vs MED) as directional signal, not a precise daily-frequency indicator.
  • Prioritized subset, not full 250: Stage 1-4 was run on the top 100 of 250 Stage-0 survivors by 3-month return, not all 250. The 150 excluded survivors (weaker but still SPY-relative-positive 3-month momentum) were not evaluated on the C1-C4 funnel this run. Full-list expansion is a candidate follow-up for a future run with a larger token/turn budget.
  • Unresolved / excluded tickers: BRK.B, BF.B, ECHO could not be resolved to a standard tradeable contract via bare-ticker search_contracts queries and were excluded from the Stage 0 universe entirely (500/503 classified, not 503/503).
  • FLAG_ANOMALOUS_PRICE (Stage 0, 3-month return > +40%): the following tickers showed an extreme 3-month move at Stage 0 and should be corroborated against corporate actions (splits, spin-offs) or data errors before acting: . Of these, MPC cleared into the HIGH tier below.
  • Additional extreme 1-year moves observed at Stage 1-4 (not caught by the 3-month Stage-0 filter, so not in the list above): DELL (+319.9% over 1yr) and CRWD (+95.5% over 1yr) both cleared to HIGH tier; these are large enough moves to warrant a sanity check against corporate actions before acting.
  • Duplicate-series check: every one of the 100 Stage 1-4 tickers' fetched weekly price series was verified programmatically to be numerically distinct from every other ticker's series (no two tickers returned byte-identical OHLC data this run).
