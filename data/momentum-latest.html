Data source & per-figure sourcing

This sandbox has no general internet access to financial data sites (Yahoo/Finviz/Wikipedia/SEC/stooq all blocked by network policy). Every price, moving-average, RSI, return and 52-week figure below was computed from live daily OHLC bars pulled directly from the Interactive Brokers market-data API (15-minute delayed feed), not from training-data memory. Each ticker: resolved via search_contracts, then 1 year of daily bars via get_price_history (ONE_YEAR / ONE_DAY / regular trading hours). SMA50/SMA200 are simple moving averages of daily closes; RSI14 uses Wilder's smoothing; 3-month return compares the latest close to the close ~63 trading days prior; the SPY benchmark (+3.10% 3-month return, close $765.72 on 2026-08-21) was pulled the same way and used as the single relative-strength bar for every ticker.

S&P 500 constituent list: GitHub dataset datasets/s-and-p-500-companies (fetched 2026-08-23). Recent index-change cross-check: S&P Dow Jones Indices press releases via web search, 2026-08-23.

Setup criterion checklist (applied to every ticker)

  • Stage A — data availability: contract resolved on IBKR AND ≥200 daily bars returned
  • Stage B — uptrend confirmation: last close > 50-day SMA AND last close > 200-day SMA
  • Stage C — momentum health: RSI(14) between 35–75 (outside this band on an otherwise-passing name → WATCH, not PASS/FAIL)
  • Stage D — relative strength: 3-month return > SPY 3-month return (+3.10%)
  • No-single-print guard: a single-day move >±4% is never allowed to drive the verdict by itself — flagged in the reason text, judged on the SMA/RSI/3-month structure
  • No-derivatives guard: universe restricted to primary US-listed common stock (STK); leveraged/inverse ETFs, options-only tickers and foreign duplicate listings excluded during contract resolution

Methodology notes

This is v2 of the screener, rebuilt after a review found the prior run had incorrectly restricted its universe to the 13 names on the account's current holdings/watchlist — the exact opposite of what a discovery screener should do. This run enforces the full 503-name S&P 500 universe on every pass, sourced independently of any holdings or watchlist data. Holdings data is used only to compute the one-sentence diversification note on each top candidate below — never to determine which tickers get screened.

Ranking within the top-30 list combines 3-month relative-strength margin over SPY (60% weight) and distance above the 200-day SMA (40% weight); this is a display ordering only, not part of the PASS/WATCH/FAIL funnel logic itself.
