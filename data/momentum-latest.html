Methodology & setup criteria

Stage 0 (bulk pre-filter): 3-month price return (2026-06-03 close → 2026-08-31 intraday) per ticker via IBKR get_price_history, discard if more than 2 percentage points below SPY's own 3-month return (+1.51%, i.e. threshold −0.49%).

Stages 1–4 (full funnel), applied only to Stage 0 survivors:
  • Setup checklist: price vs. 50-day SMA, price vs. 200-day SMA, RSI(14), distance from 52-week high, 3-month relative strength vs SPY — all computed from IBKR get_price_history (ONE_YEAR/ONE_DAY bars).
  • No-derivatives guard: universe is restricted to single-name S&P 500 operating-company equities throughout — no broad index trackers, physically-backed commodity ETCs, or covered-call income funds were candidates at any stage.
  • No-single-print guard: for every WATCH-tagged name and any borderline HIGH/MED call, the single largest 1-day move in the last 5 sessions was checked against whether removing it would flip the SMA-based trend read; flagged inline wherever it mattered (e.g. COIN, HOOD, IBKR, WFC, AXON, CVNA, CRM, NOW, PANW, SJM, VEEV, MRNA, SLB).
  • Tagging: HIGH = clears the full funnel cleanly (above both SMAs, RSI 40–70, clearly strong relative strength). MED = meets most criteria with one soft spot (e.g. strong 200-day trend but stalling under the 50-day, or modest relative strength). WATCH = real momentum but a genuine risk flag (RSI >70 overbought / <35 oversold, or a single-print concern).
Only HIGH-tagged names (88) are carried into data/momentum-latest.json with an entry price and diversification note, per this repo's format; the full 247-name cleared list (HIGH + MED + WATCH) is in the table below.

Data quality & limitations (read before trading on any figure below)

Live session in progress: every "current price" in this report is the 2026-08-31 intraday bar (today's session), not a final close — every batch flagged today's volume as well under half a typical session's, confirming the market was still trading when data was pulled.
Parallel-batch data integrity: several Stage 1-4 sub-agents caught IBKR responses to batched get_price_history calls arriving mismatched to the wrong ticker (a recurring pattern, not a one-off) — Financials A (11 tickers), Financials/Industrials B, Industrials A, and Comm Services+Energy all self-corrected via a cross-check against live get_price_snapshot quotes before scoring. Figures in this report are the post-correction, snapshot-verified numbers, but the underlying batching behavior is worth knowing about for future runs.
Possible synthetic/duplicated series: the Health Care A batch found byte-for-byte identical OHLCV series returned for two unrelated ticker pairs (CRL/ELV and INCY/PODD/HUM/IDXX) even after independent re-fetches — flagged as a possible sandbox data-source limitation. None of these names cleared Stage 1-4, so it did not affect any reported result, but it's a reason for caution on any of these four names specifically.
Other per-ticker flags: ECL — a verified genuine −13.7% single-day break (cross-checked against a live snapshot, not a data artifact), which is why it did not clear despite surviving Stage 0. J (Jacobs Solutions) — one Stage 0 pull returned an anomalous ~9-month window instead of 3 months; its Stage 0 return is lower-confidence (J still cleared Stage 1-4 on its own 1-year series). HONA (Honeywell Aerospace, a 2026 spinoff) — an early data point looked thin/illiquid (volume 100, open=close exactly); treat its Stage-0 discard as lower-confidence.

Every number in this report is either sourced live from IBKR (get_price_history / get_price_snapshot) with an as-of date, or explicitly flagged above as lower-confidence / unverifiable. Nothing was estimated from training-data memory.
