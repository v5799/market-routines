Methodology

Stage 0 — cheap bulk pre-filter

Full S&P 500 constituent list (503 tickers) sourced fresh this run, grouped by GICS sector. Each ticker's 3-month price return was pulled live via IBKR (get_price_history, THREE_MONTHS/ONE_DAY bars, regular trading hours). SPY's own 3-month return (+4.61%, close $733.24 → $767.01) sets the benchmark. Any ticker whose 3-month return fell more than 2 percentage points below SPY's (i.e. below +2.61%) was discarded — 503 → 203 survived.

C1 — no-derivatives guard

Confirmed every Stage-0 survivor is a single operating company, not a broad index tracker, physically-backed commodity ETC, or covered-call income fund. All 203 passed (the universe is single-equity S&P 500 constituents by construction).

C2 — no-single-print guard

For each survivor, computed the single largest one-day close-to-close % move within the trailing 3 months and what fraction of the entire 3-month cumulative return that one day represented. Tickers where one day accounted for >50% of the whole move were discarded as gap/earnings-day-driven rather than genuine sustained trends (this caught MRNA's flagged +173.98% Stage-0 return, which turned out to be ~98% explained by a single +177% print). 91 of 203 were cut here.

C3 — setup criterion checklist

Using 6-month daily bars, computed 20-day and 50-day simple moving averages. A ticker passed only if: (a) price > 50-day SMA, (b) price within 20% of its 3-month high, (c) price not more than 30% above its 50-day SMA (avoiding blow-off-top chases). 24 more were cut here, leaving 88 final candidates (C4).

Entry price / tag convention

HIGH = clean breakout, current price is the entry to watch. PASS = valid setup but currently extended above its 20-day SMA or already below it; entry is a named pullback level (20-day or 50-day SMA).
